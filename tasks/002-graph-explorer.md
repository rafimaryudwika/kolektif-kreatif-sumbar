# Task 002: Interactive Graph Explorer Interface

## Description

Build the primary web interface allowing non-technical users to browse, filter, and inspect entities and relationships in the database.

## Key Features

1. **Search & Filter Bar**: Filter nodes by category (`Skill`, `Location`, `Entity Type`).
2. **Visual Graph Canvas**: Render dynamic graph structures using a lightweight client-side library (`vis-network` / `cytoscape.js`).
3. **Inspector Sidebar**: Slide-over panel displaying node properties (e.g., Talent Bio, Project Year, Associated Skills) upon node selection.
